- 기준: [백엔드 MVP](001-백엔드-MVP.md), [TRD 평가 원칙](../TRD.md#11-테스트와-평가)

## 범위와 수용 기준

- 합성 서비스 요청·장애 관리 입력, 사람이 작성한 기준 설계·검토 출력, 수용 체크리스트를 제공한다. 기준 설계는 제안이며 유일한 정답이나 실제 모델 결과로 표시하지 않는다.
- CLI 한 명령으로 기존 StateGraph를 실행한다. 기준 응답 재생(외부 호출 없음), 실제 Claude 호출, 재생 모드 오류 주입을 구분한다. 실패 시 샘플 대체·자동 재시도하지 않는다.
- LangGraph debug 이벤트로 실제 단계 시작·종료·소요 시간·입출력·실패·후속 단계 생략을 기록한다. 모델 호출의 전달 데이터·프롬프트·스키마 이름·응답·토큰 정보를 로컬 진단 보고서에 담는다.
- 도구 선택 호출은 현재 구현에 없음을 표시한다. Python 검증·변환과 모델 호출을 구분한다. 판단은 코드의 검사 결과, 모델의 공개 출력에 담긴 원문 근거·가정·추적 이유·검토 제안이다.
- 로컬 HTML 보고서는 접기/펼치기와 JSON 비교를 제공하고 외부 스크립트 없이 연다. 새 웹 앱·프론트엔드·API·작업 큐는 만들지 않는다. 실행 JSON과 ERD·DDL도 함께 저장하며 SQL은 실행하지 않는다.
- 전체 본문 기록은 사용자가 실행한 로컬 CLI에 한정한다. 운영 API와 기본 Langfuse 메타데이터 정책은 유지한다. 설정은 허용 항목만 기록하고 키는 마스킹한다. 보고서는 Git 제외 경로에 저장한다.
- 자동 검사는 구조·실행 계약만 판단한다. 업무 의미 충족은 원문·기준·실제 결과를 비교하는 사람의 검토 항목으로 남긴다.

## 제외와 선택

새 의존성, 신규 그래프, 모델 추가 호출, 자동 채점용 LLM, 숨겨진 사고 과정 수집, 고객 데이터 업로드는 제외한다. 더 풍부한 입력의 실제 호출에는 CLI에서 출력 한도만 명시적으로 늘릴 수 있으며 .env 기본값은 보존한다. 실행마다 유일한 디렉터리를 사용해 실패 기록을 덮어쓰지 않는다.

## 사용 안내

[대표 시나리오 실행 안내](../../../backend/scenarios/README.md)를 따른다. 전체 본문 기록은 로컬 CLI 전용이며 신규 웹 UI·API, 모델 제공자 추상화, 새 그래프·추가 LLM 호출·새 의존성을 도입하지 않았다. 기준 출력 자체의 업무 적합성과 실제 모델의 의미 품질은 사람의 검토 대상이다.

## 실행 위치 통일 (2026-10-07)

사용자 요청에 따라 디버깅 명령은 저장소 루트의 `./debug-design`으로 통일했다. 진입 스크립트가 자신의 경로를 기준으로 backend로 이동하고 `.venv/bin/python`에 모든 CLI 인자를 전달한다. 가상환경 활성화 여부에 의존하지 않으며 기존 디버거의 종료 코드를 보존한다. 폴더 배치와 모델 호출 방식은 유지한다. README·시나리오 안내의 실행 및 curl 입력 경로를 루트 기준으로 맞췄다.

검증: 루트 `./debug-design` 기준 재생 완료(외부 호출 0회), 오류 주입 시 종료 코드 1 유지, 다른 작업 폴더에서 절대 경로 실행 및 인자 전달 확인, 가상환경 누락 안내 확인. 관련 테스트 11개, 셸 문법·ruff·문서 링크 검사 통과. 진입점 변경 검증에는 실제 모델 호출이 필요하지 않아 실행하지 않았다.
